# Arte e áudio

A IA produz propostas e recursos, mas o proprietário aprova a direção visual, sprites e música.

- Apresentar duas ou três direções visuais e alternativas sonoras antes da produção final.
- Usar Canvas, SVG, CSS e Web Audio API quando apropriado.
- Registrar ferramenta, data e condições de licença comercial dos recursos.
- Não copiar personagens, marcas, sprites ou músicas protegidas de terceiros.
- Testar legibilidade mobile, volume e mute; observar restrições de autoplay.
