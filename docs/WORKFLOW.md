# Processo de produção

1. Pesquisar mercado, registrando fontes e datas.
2. Preencher `templates/GAME_BRIEF.md` e obter aprovação do conceito.
3. Criar protótipo e validar mecânica.
4. Apresentar alternativas de arte e áudio; obter aprovação do proprietário.
5. Implementar jogo completo e integrações de portal isoladas.
6. Executar testes automatizados e testes reais no navegador; registrar evidências.
7. Conferir licenças, regras do portal e monetização.
8. Publicar somente após autorização explícita.
9. Medir sessões, retenção e receita e registrar aprendizados.

Estados: ideia → pesquisa → protótipo → arte/áudio aprovados → produção → QA → pronto para submissão → publicado → análise.

Divisão inicial experimental: ChatGPT (arcade/habilidade); Claude Code (puzzle/estratégia). O proprietário pode redefinir prioridades.
