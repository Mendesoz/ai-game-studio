# AI Game Studio

Base operacional pública e centralizador permanente de um microestúdio de jogos HTML5 com IA. Codex e Claude consultam e atualizam este repositório durante o Frutódromo e os próximos jogos.

**Meta inicial:** alcançar US$ 500/mês de receita de catálogo (objetivo, não resultado atual).

Comece por `AGENTS.md`, `CLAUDE.md` e `docs/WORKFLOW.md`. Cada jogo terá repositório próprio. Não publique credenciais nem dados comerciais privados.

- `docs/COORDINATION.md`: memória compartilhada, responsabilidades e rotina de atualização pelos agentes.
- `docs/WORKFLOW.md`: etapas de produção e aprovações.
- `docs/METRICS.md`: métricas e hipóteses comerciais.
- `docs/ART_AUDIO.md`: diretrizes de criação visual e sonora.
- `templates/GAME_BRIEF.md`: modelo de proposta de jogo.
- `projects/FRUTODROMO.md`: referência técnica somente leitura.
